# 网盘视频播放器 · 打包指南（Android APK）

> 对应开发阶段 3。按顺序做完本指南，你会得到一个可以直接装进手机使用的 APK 安装包。
> 边界说明：本指南不包含应用商店上架与资质代办。iOS 打包见文末附注（本项目 V1 仅做 Android）。

## ★ 方案 B（已选）：云端打包，电脑什么都不装 ★

**准备**：一个 GitHub 账号（github.com 免费注册）+ 你的百度开放平台 AppKey。

1. **创建仓库并上传代码**：登录 GitHub → 右上角 `+` → New repository → 名称填 `pan-video-player`，选 **Private**（私有）→ Create。
   上传方式（二选一）：
   - 网页上传：仓库页 Add file → Upload files → 把本项目的**全部文件夹内容**拖进去（注意 `.github` 是隐藏文件夹也要传）→ Commit changes；
   - 或在 WorkBuddy 里连接 GitHub 连接器，由 AI 助手直接帮你创建仓库并推送。
2. **配置 AppKey**：仓库页 Settings → Secrets and variables → Actions → New repository secret → Name 填 `BAIDU_APP_KEY`，Secret 填你的 AppKey → Add secret。
3. **一键打包**：仓库页顶部 Actions 标签 → 左侧选 "Build APK" → 右侧 "Run workflow" 按钮 → 绿色按钮确认。
4. **下载 APK**：等约 10~15 分钟（黄色转圈变绿勾）→ 点进这次运行 → 页面底部 Artifacts 下载 `pan-video-player-apk` → 解压出 `app-release.apk` 发到手机安装即可。
   （GitHub 免费额度：私有仓库每月 2000 分钟，单次打包约 15 分钟，足够用；公开仓库完全免费不限时。）

> 注意：项目已内置 `.github/workflows/build.yml` 打包配方，云端会自动安装 Flutter/JDK、生成 Android 骨架、添加网络权限并编译，你不需要改任何代码。
> ⚠️ 包名一致性：仓库默认打出包名为 `com.example.pan_video_player`。如果你在百度开放平台创建应用时填的包名不同，把 `build.yml` 第 4 步里的 `--org com.example` 改成对应前缀（如包名是 `com.xxx.pan` 则 `--org com.xxx`），否则登录会提示包名不匹配。

### 备选：Codemagic 云打包（GitHub 不可用时的替代）
codemagic.io 注册（免费额度 500 分钟/月）→ 连接 GitHub 账号与仓库 → 会自动识别项目 → Start build → 下载 APK。项目里的 `pubspec.yaml` 是标准的，Codemagic 可直接构建。

以下为**方案 A（本地打包）**指南，不需要可跳过。

## 第 1 节：安装开发环境（只需一次）

| 工具 | 用途 | 获取方式 |
|---|---|---|
| Flutter SDK | 编译打包框架 | https://docs.flutter.dev/get-started/install/windows 下载 stable 版，解压后把 `flutter\bin` 加入系统 PATH |
| Android Studio | 提供 Android SDK + 模拟器管理 | https://developer.android.com/studio 安装后打开一次 SDK Manager 装 "Android SDK Platform 34" 和 "SDK Command-line Tools" |
| JDK 17 | Android 编译需要 | Android Studio 自带（Settings → Build → Gradle 可确认），也可单独装 Temurin 17 |

验证安装（打开命令行）：

```bash
flutter doctor
flutter doctor --android-licenses   # 全部选 y 同意协议
```

`flutter doctor` 全部打勾（✓）即环境就绪。红色 ✗ 项按提示修复。

## 第 2 节：注册百度网盘开放平台（登录功能的前提，必须做）

1. 浏览器打开 **https://pan.baidu.com/union**（百度网盘开放平台）。
2. 用你自己的百度账号登录 → 点「成为开发者」→ 选择**个人开发者** → 完成实名认证（身份证信息，免费）。
3. 进入控制台 → 「创建应用」：
   - 应用类型选 **移动应用**；
   - 应用名称随意（如"网盘视频播放器"）；
   - 平台勾选 Android，包名可填 `com.example.pan_video_player`（要和打包时的 applicationId 一致）；
   - 权限范围勾选 **netdisk（网盘文件读写）** 与 basic。
4. 提交后等待审核（个人应用一般数小时~2个工作日）。通过后应用详情页会显示 **AppKey** 和 **SecretKey**。
5. 打开项目 `lib/config/app_config.dart`，把两个占位字符串替换成真实 Key。
6. （可选）如果平台要求填写回调地址，填 `oob`，与代码中 `redirectUri` 保持一致。

> 常见疑问：
> - **审核被拒**：通常是应用描述过于简单，写清楚"个人自用的网盘视频播放工具，仅调用文件列表与下载接口"再提交。
> - **接口频控**：个人应用有每日调用量限制（正常刷视频列表够用），错误码 31034 表示超频。

## 第 3 节：编译与真机安装

```bash
cd pan_video_player
flutter create . --org com.example --project-name pan_video_player   # 首次：生成 android/ 平台骨架
flutter pub get                                                      # 拉取依赖
```

按 `README.md` 第 3 步修改 `android/app/src/main/AndroidManifest.xml`（网络权限 + configChanges）。

### 手机上直接测试（推荐先做这个）
1. 手机打开「开发者选项 → USB 调试」（连点 7 次版本号开启开发者选项）。
2. 数据线连电脑，手机上弹窗选「传输文件」并允许调试。
3. 命令行执行：

```bash
flutter devices     # 应能看到你的手机
flutter run         # 编译并安装到手机，热重载调试
```

### 打包正式 APK

```bash
flutter build apk --release
```

产物路径：`build/app/outputs/flutter-apk/app-release.apk`，把这个文件发到手机上点击安装即可（需在手机上允许"安装未知来源应用"）。

## 第 4 节：签名配置（release 包正式签名，避免每次卸载重装）

未配置签名时 Flutter 会用 debug key 签名，仅自用没问题；想长期使用/分发请做正式签名：

1. 生成自己的签名文件（一次性，命令行在项目根目录执行）：

```bash
keytool -genkey -v -keystore ~/pan-player.jks -keyalg RSA -keysize 2048 -validity 36500 -alias panplayer
```

（按提示设置一个密码并记住，姓名/组织随便填。生成的 `pan-player.jks` 务必备份，丢了就无法给同一应用发更新包。）

2. 项目根目录新建 `android/key.properties`（**不要提交到 git**）：

```properties
storePassword=你设置的密码
keyPassword=你设置的密码
keyAlias=panplayer
storeFile=../pan-player.jks
```

3. 打开 `android/app/build.gradle`，在 `android {` 块内添加：

```gradle
def keystoreProperties = new Properties()
def keystorePropertiesFile = rootProject.file('key.properties')
if (keystorePropertiesFile.exists()) {
    keystoreProperties.load(new FileInputStream(keystorePropertiesFile))
}

 signingConfigs {
    release {
        keyAlias keystoreProperties['keyAlias']
        keyPassword keystoreProperties['keyPassword']
        storeFile file(keystoreProperties['storeFile'])
        storePassword keystoreProperties['storePassword']
    }
}
buildTypes {
    release {
        signingConfig signingConfigs.release
    }
}
```

4. 重新执行 `flutter build apk --release`。

## 第 5 节：高频报错排查

| 报错 | 原因与解决 |
|---|---|
| `cmdline-tools not found` / 许可协议未同意 | Android Studio → SDK Manager 装 "Command-line Tools"，再执行 `flutter doctor --android-licenses` |
| `Gradle build failed` 超时 | 国内网络拉 Gradle 慢：先执行 `flutter clean`，配置镜像（`android/gradle.properties` 加 `systemProp.http.proxyHost=...`）或使用魔法网络后重试 |
| `Could not resolve all files for configuration ':classpath'` | Gradle 版本问题：删除 `android/` 下 `.gradle` 缓存目录后 `flutter build apk --retry` |
| 登录页打开后提示"请填入你的AppKey"相关错误 | 还没执行第 2 节，或 AppKey 填错（检查前后无空格） |
| 授权成功却回到欢迎页/闪退 | 检查开放平台应用的包名是否与 APK 的 `applicationId` 完全一致 |
| 播放一直转圈/报"未能获取下载直链" | ① 文件可能违规被封禁 ② token 过期：到「我的」退出该账号重新登录 ③ 非会员大文件限速严重，等待缓冲 |
| 播放卡顿 | 属账号下载限速（百度侧规则），尝试 1.0x 倍速、稍等缓冲，或升级网盘会员 |
| `INSTALL_PARSE_FAILED_UPDATE_INCOMPATIBLE` | 手机上已有不同签名的旧版本：先卸载旧版再安装 |
| 热重载后播放器黑屏 | media_kit 属于原生资源，改完播放器代码用热重启（终端按 `R`）而不是热重载（`r`） |
